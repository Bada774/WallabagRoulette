Wallabag Roulette

A random link from your wallabag: by schedule and by click.

Connection to wallabag

Without a trailing slash. The extension will request access specifically to this address.

Take it from wallabag: menu → «API Client Management» (/developer) → «Create new client».

Data is stored in the browser (chrome.storage) without encryption. For a personal profile, this is normal.

What to Select

From entries with this tag (except archived) a random one is selected. The same tag is applied to new links.

Changing the tag does not re-tag existing entries: entries saved under the old tag will no longer be shown here (they stay in wallabag untouched).

Notifications

Saved data

Sign out removes the server address, client ID and secret, username, password and tokens from this browser. Reset everything also removes your settings, the current pick and the list of categories.
